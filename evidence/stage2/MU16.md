# MU16 — Feature Natural-Language Completion

Source dependency: MU15 checkpoint `c92b259`.

## Implemented capability

- Natural Order interpretation extracts item, quantity, optional supplier,
  delivery date, drop location, and project-bearing context.
- Complete natural Orders go directly to the existing pending-approval Task
  representation without unnecessary clarification.
- Incomplete Orders persist every supplied field and request only the first
  actually missing required value; subsequent turns advance only through the
  remaining missing set.
- Natural Meeting requests receive structured title/schedule meaning and route
  to the existing `create_meeting` handler.
- Existing ordinary Reminder lifecycle operations remain routed to the
  authoritative acknowledge, snooze, redirect, and cancel handlers.
- Structured interpretation remains non-mutating until an existing business
  handler is invoked.
