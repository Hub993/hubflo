# MU15 — Shared Date/Time Completion

Source dependency: MU14 checkpoint `e6163a7`.

## Implemented capability

- Shared ISO, month-first, day-first, and named-month calendar parsing.
- Unambiguous inference and explicit ambiguity for numeric dates without a
  decisive sender policy.
- `/`, `-`, and `.` regional separators.
- Sender timezone, date-order, date-display, and 12/24-hour configuration.
- Numeric 12-hour/24-hour clocks and spoken forms such as `at nine` and
  `quarter past nine`, with morning/evening semantics.
- Configured rendering without changing canonical naive-UTC persistence.
- Persistent Reminder date clarification with a bounded two-date candidate
  universe, atomic continuation claim, and exactly-once Reminder creation.
- Shared interpretation reused by Reminder and Inspection consumers.

## Schema migration

Existing `users` tables receive backward-compatible configuration columns:

- `date_order` (existing users default to `month_first`)
- `time_format` (existing users default to `12h`)
- `date_display` (existing users default to `month_first`)

The existing `timezone` column remains authoritative for sender-local dates.
